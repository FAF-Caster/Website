# FAF Caster project website

Static, dependency-free project landing page for FAF Caster.

## Publish on GitHub Pages

After merging this change into `main`:

1. Open **Settings → Pages** in `FAF-Caster/FAF-Caster`.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. The site should be available at **https://faf-caster.github.io/Website/** after GitHub finishes deploying it.

No API keys, hosting bills, build pipeline or JavaScript framework required.

## Feedback

The feedback form prepares a GitHub Issue with the selected category and message. GitHub handles authentication and final submission. The website does not store or send feedback to a custom server.

To edit text, styles or links, update `index.html`. The site uses relative anchor links and absolute repository links to work on GitHub Pages project URLs.
