Getting started

From game to stream

The Windows installer includes the desktop app, dashboard and telemetry Bridge. The separate FAF UI mod must still be installed and enabled.

01 · INSTALL

Download and run the latest Windows installer. Your Start menu shortcut is created automatically.

02 · ENABLE

Install and enable the separate FAF Caster UI mod.

03 · CONNECT

Launch the companion and use the supported observer workflow.

04 · CAST

Use the dashboard and available OBS browser overlays.
